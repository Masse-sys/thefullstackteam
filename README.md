# The Fullstack Team

Ett repo-baserat operativsystem för ett AI-native utvecklingsteam som arbetar helt genom Codex.

## Syfte

Det här repot är inte en produktapplikation. Det är den återanvändbara arbetsmodellen för att:

- ta en idé från samtal till GitHub Issue
- planera och bryta ned arbete
- låta Codex-agenter skriva all kod och dokumentation
- arbeta i isolerade branches och worktrees
- köra tester, säkerhetskontroller och kodgranskning
- behålla mänskliga beslutspunkter där risk eller produktansvar kräver det

## Börja här

1. Läs [`AGENTS.md`](AGENTS.md) för teamets gemensamma regler.
2. Läs [`PROJECT_PROFILE.md`](PROJECT_PROFILE.md) för projektets uppdrag.
3. Läs [`docs/chatflows/chat-routing.md`](docs/chatflows/chat-routing.md) för hur ChatGPT och Codex används.
4. Läs [`docs/automation/issue-intake.md`](docs/automation/issue-intake.md) för idé-till-Issue-flödet.
5. Använd en separat Codex-chatt per konkret utfall eller GitHub Issue.

## Princip

ChatGPT/Control Room är produktens och teamets styrning. Codex är verkstaden. GitHub är källan till sanning för arbete, beslut och leveranser.
