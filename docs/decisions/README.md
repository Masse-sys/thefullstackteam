# Architecture Decision Records

Större tekniska beslut ska dokumenteras som korta ADR:er i denna mapp.

## Mall

```text
# ADR-NNN: Titel

Status: proposed | accepted | superseded | rejected
Datum:
Beslutsägare:

## Kontext

## Alternativ

## Beslut

## Konsekvenser

## Risker och uppföljning
```

Arkitektagenten får skriva förslag. Människan godkänner beslut som påverkar produkt, säkerhet, data, kostnad eller långsiktig plattform.
