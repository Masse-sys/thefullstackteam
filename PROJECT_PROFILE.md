# Project profile

## Identitet

- Namn: The Fullstack Team
- Typ: Codex-teamets operativsystem och återanvändbara arbetsmodell
- GitHub: `Masse-sys/thefullstackteam`
- Status: Bootstrap, ingen produktkod ännu

## Målbild

Skapa ett stackagnostiskt utvecklingsteam där användaren kan arbeta genom naturligt språk och Codex-agenterna utför analys, planering, implementation, testning, granskning och releaseförberedelser.

## Teknikpolicy

Ingen applikationsstack är vald i detta repo. När ett framtida produktrepo skapas ska det ha en egen projektprofil med:

- språk och ramverk
- pakethanterare
- bygg-, test- och lintkommandon
- runtime och deploymentmiljö
- integrationskatalog
- datakänslighet och retention
- kostnads- och driftgränser

Teamets processer ska vara stackagnostiska. Stackbeslut ska dokumenteras per produkt, inte bakas in i teamets kärnregler.

## Första leverans

Den första leveransen är att få själva teamet att fungera:

1. Codex-instruktioner och custom agents
2. chatt- och routingmodell
3. idé-till-GitHub-Issue-flöde
4. GitHub Issue- och Pull Request-mallar
5. CI- och branchguardrails
6. mänskliga beslutspunkter
7. pilot med en verklig produktfeature senare
