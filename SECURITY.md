# Security policy

## Grundregel

Detta repo får inte innehålla riktiga secrets, personuppgifter, CV:n, ljudfiler eller produktionsloggar.

## Agentgränser

- Security Reviewer är read-only.
- MCP-verktyg ska ha minsta möjliga behörighet.
- Skrivoperationer ska ha tydlig scope och vara separerade från läsoperationer när det går.
- Produktion, destruktiva migrationer och behörighetsändringar kräver mänskligt godkännande.

## Rapportera problem

Skapa inte publika detaljer om en säkerhetsbrist innan den är bedömd. Använd ett privat GitHub-flöde eller kontakta repoägaren direkt.
